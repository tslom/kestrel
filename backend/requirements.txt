# Voice (app/voice.py). Audio is transduced locally and only the transcript
# reaches the model, so these are the ears and the mouth both:
#   parakeet-mlx  — ASR on the Metal GPU (~2.5GB model, pulled on first use).
#                   The Apple-silicon port is the whole point; NVIDIA's newer
#                   Nemotron ASR is a stronger model with no Metal path.
#   openwakeword  — the two cheap gates in front of it, Silero VAD (~1MB) and
#                   the wake-word spotter, so the 600M model is not running
#                   all day and nothing becomes text until it's summoned.
#   onnxruntime   — what both of those gates run on.
# Speech out is macOS `say`, and the one system dep is ffmpeg (parakeet-mlx
# shells out to it). The two models are optional — voice.py imports them
# inside the functions that need them, so an install without them still
# boots, /api/voice/status reports what's missing, and the UI hides the mic.
# numpy is the exception: it is what a frame of audio *is* here, so voice.py
# needs it at import time and main.py imports voice.py.
#   mlx-audio + misaki — Kokoro-82M for speech out, on Metal. `say` is still
#     the fallback and still the floor, so these stay optional like the two
#     above: without them voice.kokoro_ready() is False and synthesis drops
#     back to `say` rather than failing. misaki is Kokoro's G2P and is not
#     optional *to Kokoro* — mlx-audio imports cleanly without it and then
#     fails on every sentence, which is why kokoro_ready() checks for both.
#     misaki pulls spacy and downloads en_core_web_sm (~13MB) on first use.
